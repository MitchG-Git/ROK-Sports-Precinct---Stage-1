## 4. CRITICAL cross-checks (as requested)

### 4.1 Denis's ~1,883 m total in-ground pipe claim — culverts ARE inside it

- Pipes only (Section 3.1): **1,742.87 m** — 140 m short of the claim.
- Pipes + culverts: 1,742.87 + 130.76 = **1,873.63 m** — within 9.4 m (−0.5%) of ~1,883 m.
- **Conclusion: the ~1,883 m figure only reconciles if the RCBC culvert runs are included in it.** The exact 1,883 figure is not printed anywhere in this set (nearest reconstruction from the legends is 1,873.63 m); treat the residual ~9 m as rounding/claim imprecision. ## 6. Anomalies / flags

Lengths reconcile per size, so it is the same pipe network — but the material description (and "PN100", which is not a real class for this product) is wrong. Price as PP (e.g., StormPRO/equal) or confirm intent.
2. **Item-name typos in legend:** "RPC 600 CLASS 3" (= RCP 600 CL3), "RCBO 750 X300" (= RCBC 750x300).
3. **Kerb chutes uncounted:** 9 kerb chutes in F1310 (03-02, 03-03, 04-02, 13-02…18-02, per F1325 detail) have no EA count anywhere in the take-off — only their rock/matting area. If chute construction (concrete invert, kerb transitions) is a cost item it is currently unquantified.
